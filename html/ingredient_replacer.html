You found the perfect recipe, but you're missing one or two ingredients... wonder if you have a substitute lying around at home?

Enter the ingredient you want to find a substitute for!

Inner Workings

Listens for user input changes in real time. User input is captured by pressing their "Enter" key or by clicking the "Submit" button.

Calls Spoonacular’s ingredient substitution endpoint, returning a set of suggested alternatives. A secondary API call fetches more contextual information about the ingredient, such as estimated cost and the store aisle where it is commonly found in. This provides users with real-world guidance, not just alternatives.

If no substitutions are found, a friendly message is shown advising the user to check for typos or avoid plurals. This helps reduce confusion from empty or malformed results.
