Recipe Filter

Fill our your preferences and we'll help you generate a recipe! If something doesn't apply, leave it blank.

Filter Options Explained

Cuisine: Pick a specific cuisine like Italian, Japanese, or Mexican.

Allergies: Specify what ingredients you are allergic to so the filter can avoid recipes with them.

Dietary Restrictions: Search for meals that fit your needs (ex: vegetarian, vegan, pescatarian)

Ingredients: Include ingredients you want to use and we'll generate a recipe that requires it.

Inner Workings

Each input field (cuisine, allergies, diet, ingredients) stores the latest user values in variables that are later injected into the API request. Users aren’t required to fill every field, and multiple items can be entered per field, separated by commas.

To keep the experience fresh and exciting, the Recipe Filter randomly selects a recipe from a list of suitable matches instead of always returning the same result for identical inputs.

Before displaying the recipe, raw data is cleaned and reformatted for clarity. Time is converted into hours and minutes. Diets, ingredients, and instructions are processed into clean HTML lists, and a recipe summary is pulled from the API for quick preview.

If no results match the user’s input, a custom message is rendered to inform them.

Clicking the "Clear" button resets all inputs and internal variables to their default state, allowing users to start over easily without refreshing the page.
